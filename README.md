# One Line, No Deadline Met

A single-line joke excusing a missed deadline.

> I didn't miss the deadline — I gave it a head start and it never looked back.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). The file contains exactly the line: one sentence, UTF-8, 77 characters / 79 bytes / 17 words — inside the 1–200 character gate, with no trailing newline.

## How it was chosen

Ten candidate excuses were written and duelled pairwise against the judge brief (a real joke with a turn, single sentence with its punch at the end, sounds like a cornered person, fresh angle). See [CANDIDATES.md](CANDIDATES.md) for the full list and the winner's rationale.
